# meytel-planner

**Purpose**: Migration scheduling, milestone generation, checklist creation based on current project state.

**Key Responsibilities**:
- Analyze project scope and complexity
- Generate migration timeline with milestones
- Create task checklists per plugin/theme
- Identify critical dependencies and risk areas
- Coordinate with repo-explorer to map `wp-content` structure

**Commands**:
- `/plan-migration` — Initiates planning workflow

**Entry point**: Root of repository
**Focus directories**: `.opencode/`, `wp-content/plugins/`, `wp-content/themes/`
