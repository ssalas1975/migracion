# meytel-tester

**Purpose**: Functional test case execution on Staging environment.

**Key Responsibilities**:
- Define and execute test scenarios (Checkout, Forms, User Registration)
- Validate data integrity after migration
- Verify shortcode functionality
- Confirm theme rendering correctness
- Report functional regressions

**Commands**:
- `/verify-staging` — Runs functional verification suite

**Prerequisites**: Staging environment connection (credentials stored in agent config, not repo)
