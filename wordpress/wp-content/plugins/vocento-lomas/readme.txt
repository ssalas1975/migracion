Generador de Lo más para Vocento

== Description ==
El plugin permite configurar widgets con lo último de varias fuentes a nivel de red o a nivel de site.

== Installation ==
Tras activar el plugin aparecerá dentro del menú ajustes (en el site) la opción de \"Vocento Lo más\".
En la red aparecerá en el raíz del menú la opción \"Vocento Lo más\"
