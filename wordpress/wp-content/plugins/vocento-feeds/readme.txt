Generador de feeds para Vocento

== Description ==
El plugin permite generar feeds a nivel de red o a nivel de site utilizando una fuente de datos XML  y un fichero XSLT.

== Installation ==
Tras activar el plugin aparecerá dentro del menú ajustes (en el site) la opción de \"Vocento feeds\".
En la red aparecerá en el raíz del menú la opción \"Vocento feeds\"
